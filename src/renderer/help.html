Command palette

Ctrl+K opens a search box over everything the browser can do. Type a few letters — they need not be next to each other, so nwtb finds New tab — then Enter. With nothing typed it shows your other open tabs first, then tabs you recently closed, then the commands.

Switch to Jump to any open tab by its title. Faster than hunting the strip when tabs have shrunk to favicons. Ctrl+K
Reopen The last 25 tabs you closed, newest first. Amnesia tabs are never listed — an undo list that could resurrect them would be a record that they existed. Ctrl+Shift+T
Commands New tab, amnesia tab, bookmark, blocking, Compatibility Mode, install this site, settings, manual, downloads, DevTools. Enter
Fallback If nothing matches what you typed, Enter searches the web for it. Enter

Tabs

Resize Tabs shrink as you open more: full, then close-button-only on the active tab, then favicon only. Past that the strip scrolls and keeps the active tab in view. —
Reorder Drag a tab sideways along the strip. Drag
Tear out Drag a tab downwards, away from the strip, and release: it opens in its own window and closes here. Amnesia tabs refuse — moving one to a new window would put it back in the recording session. Drag down
Split view Two tabs side by side in one window. The tab you are on is the left pane, so switching tabs changes the left side and leaves the companion in place. Right-click a tab and choose Show beside the current tab, or press Ctrl+Shift+E to pair with the neighbouring tab. Both tabs get an underline in the strip. Closing either pane, or switching to the companion, ends the split. Widen a pane from the command palette. Ctrl+Shift+E
Right-click Reload, duplicate, open in a new window, copy address, open in your default browser, close, close others, close to the right. —

The omnibox

Type anything. A hostname goes straight there; anything else goes to your search engine — DuckDuckGo unless you changed it in Settings → Search engine, where there are ten to pick from. A new tab puts the caret here already, so you can just start typing.

Right-clicking a page

Links offer open in new tab, open in amnesia tab, open in new window and copy link address. Images add open, copy address and save. Selected text offers copy and a search for it. Anywhere else gives back, forward, reload and inspect.

What gets written down

Everything lives in one SQLite file on your machine. Nothing is uploaded anywhere, because there is nowhere to upload it to.

Situation History Full page text Cookies
Normal tab recorded captured kept
Amnesia tab never never gone on close
Login / checkout / banking pages recorded skipped kept
Domains on your never-remember list never never kept
With “Record history” off never never kept
This page and the new tab page never never n/a

Honest limitation: the login/checkout exclusion is pattern matching on hostnames and paths — accounts.*, /login, /checkout and friends. A logged-in dashboard on an ordinary URL will have its text captured. Use an amnesia tab, or add the domain to the never-remember list in Settings → Memory. Camera, microphone and location are denied to every site with no prompt, because the prompt UI does not exist yet.

Settings

Get started What opens on startup, and which page counts as home.
Search DuckDuckGo, Google, Brave, Bing, Yandex, Yahoo, Startpage, Ecosia, Mojeek or Wikipedia. Omnibox suggestions can be switched off entirely.
Appearance Seven accent colours, tab width, animations on or off, website scrollbars restyled to match the browser, and which toolbar buttons are shown.
Memory Turn history and text capture off, decide whether amnesia tabs count blocked requests, see what is stored, and manage the never-remember list — including wiping one site's history on demand.
Privacy Forget everything, with an option to clear cookies and sign you out of sites at the same time. Bookmarks are always kept.

Internal pages

Sleeping tabs

A tab left alone for a while has its page thrown away and its memory handed back. The tab stays where it is, marked with a ring around its favicon, and reloads when you return to it.

Its Back and Forward history comes back with it — the whole list, at the same position. The page is genuinely reloaded, so it returns scrolled to the top rather than where you left it.

The tab you are looking at, its split-view companion and anything playing sound are never touched. Turn it off, or change the delay, in Settings → Performance.

Pinned tabs and groups

Right-click any tab to pin it. Pinned tabs shrink to their favicon, sit at the front of the strip, and come back when the browser is reopened — even when it is set to start with a new tab.

The same menu files tabs into a group. A group is a coloured, named run of adjacent tabs; click its chip to rename it, recolour it, add a tab to it, ungroup it or close it in one go. Dragging a tab in among a group's tabs joins it; dragging it clear of them leaves.

Ctrl-click tabs to select several at once, or shift-click to take the run between two. Whatever the tab menu does next, it does to all of them.

Shift+Alt+C new tab in the current group · Shift+Alt+W close the current group
